# Flashh AI Landing Page

A premium, modern, conversion-focused landing page for Flashh AI — the conversational workflow builder that turns ideas into automations.

## Tech Stack

- React 18 (Create React App)
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

```bash
cd frontend
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Build for Production

```bash
cd frontend
npm run build
```

## Structure

- `frontend/public/` — Static assets and HTML shell
- `frontend/src/` — React application source
- `frontend/src/components/` — Landing page section components
